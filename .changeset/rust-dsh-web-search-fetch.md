The isolated Rust client can search and fetch through explicitly configured substitutes. Both tools stay off, and are not advertised, until search names a model and fetch is enabled. Domain policy, proxy routing, loopback exceptions, and private-address blocks apply at startup. Official hosts are refused. Authentication, rate-limit, redirect, cancellation, and network failures return no page text. Sources and truncation stay visible in the command, JSON, and dsh tool result.
