Search, rename, and resume dsh sessions from the welcome list, `/resume`, the agent dashboard, and `codsh --rust sessions`. Manual titles outrank generated titles. A refused switch keeps the current write owner. A same-directory resume that is already active does not close the live session, and the open picker or dashboard shows `already active`. The launcher forwards the dashboard startup settings.
