Run one plain prompt through the isolated Rust client and released dsh. `-p`/`--single`, `--prompt-file`, and `--prompt-json` print the final answer on stdout. `--cwd`, resume, tool filters, and `--max-turns` affect the dsh session; unavailable specialized flags fail explicitly. JSON output stays a later ticket.
