codsh

一句话需求，变成能运行的代码。

面向 DeepSeek 和兼容端点的终端编码 agent。
/ship 自带即时任务流程全景图（终端双环浮层与本地 Web 流程图），确认计划后，交给 codsh 实现和验证。

开始使用 看看生成的作品

安装，然后说出你的想法。

需要 Node.js 22.19+。在环境变量或 .env 中设置 DEEPSEEK_API_KEY。自带即时任务流程全景图，支持终端（Ctrl+G）与本地 Web 双重呈现。

安装与配置说明 
npm install -g @deepseek-ai/dsh codsh-cli
codsh
/ship <你的一句话需求>

一句话，能做出什么？

从原始需求，到可以试玩的二战 Web 游戏、国际商城与音乐播放器。
